# Auto Layout (Geode 모드, 지메 2.2081 / Geode v5.11.2)

에디터에서 직접 플레이하면, 플레이하는 동안 내 주변에 맵이 만들어지는 모드.

## 사용법
1. 에디터에서 맵 열기 → 화면 위쪽 `GEN: OFF` 버튼을 눌러 `GEN: ON` (옆의 `Settings` = 설정 창)
2. 플레이테스트 시작 → 그냥 플레이. 내가 하는 행동에 따라 기술이 만들어짐
   - 공중에서 클릭 → 그 자리에 공점 (공점 체인). 난이도가 오르면 빨강·검정·대시 공점, 볼에서는 파랑·초록 공점
   - 대시 공점으로 대시 → 대시가 끝난 자리 바로 뒤에 가시 벽 (스토퍼)
   - 점프 후 내려올 때 가끔 발밑에 발판이 생김 → 계단. 발판 아래 땅에는 가시가 깔림
   - 달리는 중 가끔 발 앞에 점프 패드
   - 비행기·스윙·UFO로 수평 비행 → 좁은 일자비행 터널
   - 웨이브·UFO·볼·거미로 연타 → 양쪽 벽에 가시가 붙은 스팸 통로
   - 몇 초마다 내 앞에 게임모드/속도/미니/중력 포탈 (중력 포탈은 비행 구간에서만)
   - 지나온 자리 바로 뒤에 블록·가시
3. 플레이테스트 정지 → 포탈 위아래를 벽으로 막음 (포탈을 피해 갈 수 없게)
4. `GEN` 은 직접 끌 때까지 ON. 켠 채로 다시 플레이테스트하면 이전 생성물(에디터 레이어 77)을 지우고 새로 만듦. 결과물 테스트는 `GEN: OFF` 로

## 게임모드별 생성
| 모드 | 만들어지는 것 |
|---|---|
| 큐브 | 점프 아래 가시 줄, 블록+가시, 매달린 블록, 계단 발판, 패드, 공점 |
| 로봇 | 큐브와 같고, 높은 점프 아래에는 2칸 기둥+가시 |
| 비행기 | 매끈한 통로, 급상승·급하강 구간에 가시, 수평 비행은 일자비행 터널 |
| 웨이브 | 경로에 바짝 붙은 벽 + 벽 가시, 연타 구간은 양쪽 가시 |
| UFO | 3~5칸마다 구멍 하나 뚫린 관문 벽 |
| 볼·거미 | 내가 없는 쪽 면(바닥/천장)에 가시. 천장으로 넘어간 구간은 바닥에 가시 |
| 스윙 | 비행기보다 조금 넓은 통로 |

## 설정
- Build while playing: 끄면 블록·가시는 정지할 때 한꺼번에 생성 (공점·포탈은 항상 실시간)
- Mode: 사용할 게임모드 (여러 개 선택 가능)
- Frame perfects / Frame perfect FPS: 큐브·로봇 점프 중 프레임퍼펙 개수, 60 / 120 / 240
- Difficulty (1~5): 벽 간격, 가시 줄 길이, 최고 배속, 나오는 공점 종류, 일자비행 터널 폭, 발판·매달린 블록 빈도가 전부 달라짐
- Obstacle density, Jump orbs, Jump pads, Platforms, Gravity portals, 속도/미니 포탈

## 빌드
레포에 이 폴더 내용을 올리면 Actions 가 `.geode` 를 만들어 줌 (Artifacts → AutoLayout-geode).

플레이 중에 플레이어 위치에 오브젝트를 놓는 방식은 ProfDragon 의 Layout Generator 모드를 참고함.
