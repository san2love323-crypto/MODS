# Auto Layout

Builds a layout around the way **you** play.

1. Open a level in the editor and press the **GEN** button (top of the screen) so it says `GEN: ON`. The **Settings** button next to it opens the options.
2. Press playtest. Random gamemode / speed portals are placed ahead of you. Just play: jump, fly, click however you like.
3. Blocks, spikes and frame-perfect jumps appear right behind you while you play, built around the exact path you took, so the level is always beatable the way you played it.
4. `GEN` stays on until you turn it off. Every playtest with `GEN: ON` removes what was generated before (editor layer 77) and builds a new layout from the start.
5. Turn `GEN` off to test the result. Objects you placed yourself are never deleted.

Settings: build while playing, which gamemodes to use, how many frame perfects (60 / 120 / 240 fps), difficulty, density, length.
